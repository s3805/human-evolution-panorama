# 🧬 人类演化全景图

> 从 700 万年前的乍得沙赫人，到今天 80 亿智人——一页读懂人类演化史。
>
> From *Sahelanthropus tchadensis* 7 million years ago to 8 billion *Homo sapiens* today — the complete panorama of human evolution, in a single file.

**[🌐 在线预览（GitHub Pages）](https://s3805.github.io/human-evolution-panorama/)** · **[📦 下载单文件](https://github.com/s3805/human-evolution-panorama/raw/main/人类演化全景图.html)**

## ✨ 这是什么

一个**零依赖、单文件**的中文科普数据可视化页面：整个项目就是一个 HTML 文件（约 170KB），不引用任何 CDN、字体、图片或框架，双击即可在浏览器打开，也可直接分发、离线保存。

内容整合了截至 **2026 年 9 月**的古人类学研究进展，覆盖 26 个人族物种，并对所有存争议的结论（如巨颅人命名、郧县人"深分化"假说）做了明确标注。

## 🛠 技术要点

- **零依赖单文件**：全部图表（谱系树、甘特图、脑容量曲线、人口曲线、地图、地球）均由原生 JS + SVG/Canvas 程序化生成
- **3D 地球**：正交投影 + 大圆插值（slerp）实现的贴球飞行弧线，支持拖拽旋转与自动自转，跨日界线航线自动走极地侧
- **参数化复原头像**：26 个物种的侧影线稿由真实数据驱动——脑容量决定颅穹隆尺寸，类群决定眉骨/颌部/颏部形态，傍人属带矢状脊
- **明暗双主题**：☀️/🌙 一键切换（localStorage 记忆），全部图表配色双主题适配
- **跨图表联动**：甘特图、脑容量图、物种卡片、谱系树之间任意跳转定位
- **非线性时间轴**：幂函数压缩 700 万年时间跨度；人口图横轴分段压缩
- **无障碍与工程化**：键盘章节导航（←/→）、`prefers-reduced-motion` 降级、focus-visible、打印样式（可直接打印成讲义）、Meta/OG 标签
- **性能**：动画仅在视口内运行（IntersectionObserver），DPR 感知的 Canvas 渲染
